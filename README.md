## 💡 주요 구현 내용

> 각 페이지별로 구현한 기능과 기술적 고려사항을 설명해주세요.

### 1. 기본 페이지 및 레이아웃

- **DashboardShell**: 고정된 GNB(상단 네비게이션 바)와 LNB(좌측 네비게이션 바)를 포함한 레이아웃 구조
- **GNB**: 보기 타입 전환 드롭다운 포함, 고정 위치로 스크롤 시에도 항상 표시
- **LNB**: 현재 페이지에 따라 활성화 상태 표시 (`aria-current` 속성 활용), 서비스 게시판 하위 페이지에서도 활성화 유지
- **콘텐츠 영역**: 스크롤 가능한 메인 콘텐츠 영역, 레이아웃 격자 시스템 활용

### 2. 공통 컴포넌트

- **모달**:
  - **ModalStack**: Zustand를 활용한 모달 스택 관리 시스템
  - 다중 모달 지원 (z-index 자동 증가)
  - ESC 키, 외부 클릭으로 모달 닫기
  - 모달 열림 시 body 스크롤 방지
  - Portal을 활용한 DOM 외부 렌더링
  - AlertModal, ConfirmModal, DeleteIssueModal 등 다양한 모달 타입 지원

- **페이지네이션**:
  - 현재 페이지 하이라이트 표시
  - 이전/다음 버튼 제공
  - 페이지 번호가 많을 경우 ellipsis(...) 처리
  - 접근성 고려 (aria-current 속성 활용)
  - 페이지 변경 시 React Query를 통한 데이터 자동 갱신

- **드롭다운**:
  - 키보드 네비게이션 지원 (화살표 키, Enter, Escape)
  - 외부 클릭 시 자동 닫기
  - 포지셔닝 자동 조정 (useOverlayPosition 훅)
  - Roving Focus 패턴 적용

### 3. 서비스 게시판

- **게시글 목록**:
  - **ListView/CardView**: 리스트와 카드 뷰 전환 기능
  - **검색 기능**: React Query를 활용한 실시간 검색, 엔터 키 및 버튼 클릭 지원
  - **페이지네이션**: 한 페이지당 10개 게시글 표시, 페이지 이동 시 자동 데이터 갱신
  - **더보기 메뉴**: 각 게시글별 수정/삭제 액션 제공
  - **빈 상태 처리**: 검색 결과가 없을 때 적절한 메시지 표시
  - **로딩/에러 상태**: React Query의 isPending, isError 상태 활용
  - **보기 타입 저장**: localStorage를 통한 사용자 선호도 저장

- **게시글 상세**:
  - 게시글 제목, 내용, 작성자, 등록일시 표시
  - 목록으로 돌아가기 버튼
  - 더보기 메뉴를 통한 수정/삭제 기능
  - 삭제 시 확인 모달 표시

- **게시글 등록/수정**:
  - **BoardForm**: React Hook Form을 활용한 폼 관리
  - **유효성 검사**: 제목과 내용 필수 입력 검증
  - **페이지 이탈 방지**:
    - `useBeforeUnload`: 새로고침 시 브라우저 기본 beforeunload 이벤트 처리
    - `useRouteChange`: 뒤로가기 및 라우팅 변경 시 ConfirmModal 표시
    - 폼이 변경된 경우에만 경고 표시 (`isDirty` 상태 활용)
  - 등록/수정 성공 시 자동 페이지 이동

### 4. 추가 요구사항

- **게시글 작성 중 페이지 이동 방지**:
  - 새로고침 시도 시 브라우저 기본 다이얼로그 표시
  - 뒤로가기 시도 시 ConfirmModal 표시
  - LNB 메뉴 클릭 등 라우팅 변경 시 ConfirmModal 표시
  - 폼 제출 중(`isSubmitting`)에는 경고 표시하지 않음
  - Next.js 라우터의 pathname 변경 감지 및 이전 경로로 복원
